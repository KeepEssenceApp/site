存得下很多，只留精华。

先帮我看清，再由我决定。

你随手存进来的文章，助手先读一遍，告诉你它讲了什么、值不值得花时间。留不留，你说了算。

申请内测

存了几百条，一条都没回头看？不是你懒，是没人先帮你看一眼。

怎么用

  1. 存入在网页上粘贴链接、文字或图片；电脑上装了浏览器扩展的，点一下就存。
  2. 看清几分钟内，助手给出四项解读：内容概述、关键事实、最多三条要点，和一个判定。
  3. 你决定值得的，点「深挖」；不感兴趣的，标「不感兴趣」。每晚的每日摘要帮你收个尾。
示例

任务队列里，怎么让一份活只归一个人

内容概述
用「租约」让一份任务同一时间只归一个人做，过期自动放回队列。
关键事实
文章 · 约 3200 字。
要点
  • 认领要带期限，过期自动放回。
  • 交回要能重放，同一份交两遍只留一份。
  • 续期只能由持有者做。
判定
值得深挖

每日摘要

每晚 21:00 之后，助手写一页每日摘要：值得深挖的、其余的，再加一个睡前问题。看完点「读了，晚安」。摘要从已经解读过（含没能解读出结果的）、还没进过摘要的条目里挑，每份有上限，所以可能有前几天的；当天存的不一定都在这一份里，没删除的之后可能进某一份，但不固定是哪天。

深挖与笔记

挑出值得的那一条，和助手聊透，存成你自己的笔记。笔记可以快速查找，也可以下载成 Markdown。留下笔记的那天，月历上会亮一个金点。

月历

一天一个圆点。金点：那天留下了笔记。

接上你自己的助手

一个 MCP 地址，就能接入你自己用的、支持 MCP 的助手。没有自己的助手也没关系，内置助手会出解读和每日摘要，内测期间不收费。

现在能用什么

可以

  • 网页：电脑和手机的浏览器都能打开
  • 浏览器扩展：Chromium 内核的浏览器，需手动安装，还没上架商店，安装步骤随邀请发
  • 内置助手出解读和每日摘要
  • 笔记
  • 用 MCP 接入你自己的助手

还没有

  • iPhone App 暂不开放安装
  • 浏览器扩展在 Chrome、Edge、Brave 里还没有逐个试过，目前只在 Chromium 里测过

有些网页的正文读不到，比如要登录或要验证的页面。这时会如实显示「没取到内容」，并附上原文链接。

不用 Cookie。数据怎么保留、保留多久，以正式的隐私说明为准（正在定稿）。
